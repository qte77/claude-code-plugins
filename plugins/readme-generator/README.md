# readme-generator

Generate and audit README.md files for repos, GitHub accounts, and organizations.

## Skills

- **writing-readme** — Generates or updates README.md files across three scopes — repo (with project-type detection), account (GitHub user profile), and org (organization profile)
- **auditing-readme** — Audits README.md files against best practices for repos, accounts, or orgs; detects missing sections, stale links, inconsistent formatting, and convention violations; a many-repo scope can fan the per-repo checklist out as a parallel dynamic workflow (`workflows/audit-repos.js`)

## Install

```bash
claude plugin install readme-generator@qte77-claude-code-plugins
```
